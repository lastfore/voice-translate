# 项目删除功能测试验收方案

> **关联文档：** [项目删除完整清理方案.md](./项目删除完整清理方案.md)  
> **测试脚本：** `tests/run_playwright_project_delete.py`、`tests/test_store.py`、`tests/test_paths.py`  
> **版本：** v1.0  
> **日期：** 2026-07-25

---

## 1. 目标与范围

验证项目删除三档 scope（`metadata` / `artifacts` / `all`）的路径枚举准确性、Store 删除行为、Web UI 预览与确认流程，以及删除后的列表刷新与状态清空。

| Tier | 档位 | 用例数 | 依赖 |
|------|------|--------|------|
| 1 | `--unit` | DEL-UT-01 ~ 08 | 无 GPU；临时目录 fixture |
| 2 | `--smoke` | DEL-PW-01 ~ 06 | Web UI 服务 |
| 3 | `--e2e` | DEL-PW-07 ~ 10 | Web UI + 临时项目 fixture |
| 4 | `--negative` | DEL-PW-11 ~ 13 | Web UI + 临时项目 |

**前置条件**

- 仓库根：`D:\code\voice-translate`（或 `VOICE_TRANSLATE_ROOT`）
- Web UI：`http://127.0.0.1:7860/`（`PIPELINE_UI_URL` 可覆盖）
- Playwright：`pip install playwright && playwright install chromium`
- Legacy 用例源文件：`input/test.flac`、`input/test.lrc`
- 默认对照项目：`mysong`（**E2E 用例不得删除 mysong**）

## 2. 执行命令

```powershell
# 单元测试（无需 Web UI）
cd D:\code\voice-translate
py -m pytest tests/test_paths.py tests/test_store.py -v -k "delete or collect_project"

# 仅单元档位
py tests/run_playwright_project_delete.py --unit

# 启动 Web UI（另开终端）
separator-env\Scripts\python.exe -m webui.pipeline_app

# UI 快检
separator-env\Scripts\python.exe tests/run_playwright_project_delete.py --smoke

# E2E 删除（自动创建/清理 pwdel_ 前缀临时项目）
separator-env\Scripts\python.exe tests/run_playwright_project_delete.py --e2e

# 负向用例
separator-env\Scripts\python.exe tests/run_playwright_project_delete.py --negative

# 全量（执行后自动更新本文档执行记录）
separator-env\Scripts\python.exe tests/run_playwright_project_delete.py --all --update-doc

# 单用例调试
separator-env\Scripts\python.exe tests/run_playwright_project_delete.py --case DEL-PW-03 --update-doc
```

## 3. 用例清单

### Tier 1 — 单元测试（`tests/test_paths.py` / `tests/test_store.py`）

| ID | 名称 | 步骤摘要 | 通过标准 |
|----|------|----------|----------|
| DEL-UT-01 | 枚举 metadata | 创建 `output/.projects/foo/project.json` | `collect_project_artifacts("foo").metadata` 含该目录 |
| DEL-UT-02 | 枚举 artifacts | 写入 slices/converted/merged/separated stems | `artifacts` 列表含全部四类路径 |
| DEL-UT-03 | 枚举 inputs | 写入 `input/foo.flac`、`input/foo.lrc`、`input/foo/reference.wav` | `inputs` 列表含三者 |
| DEL-UT-04 | scope=metadata | `delete_project("foo", scope="metadata")` | 仅 `.projects/foo` 消失；产物与 input 保留 |
| DEL-UT-05 | scope=artifacts | 完整 fixture 后 `scope="artifacts"` | metadata + output 产物删除；input 保留 |
| DEL-UT-06 | scope=all | 完整 fixture 后 `scope="all"` | input + separated + 全部产物 + metadata 均删除 |
| DEL-UT-07 | 不存在项目 | `delete_project("nonexistent", scope="all")` | 不抛异常；返回空列表或明确错误 |
| DEL-UT-08 | 预览 API | `preview_project_deletion("foo", "all")` | Markdown 含 `input/` 与 `output/` 路径行 |

### Tier 2 — UI Smoke

| ID | 名称 | 步骤摘要 | 通过标准 |
|----|------|----------|----------|
| DEL-PW-01 | 删除面板可见 | 展开侧边栏「删除项目」 | 存在范围 Radio、预览区、确认勾选、删除按钮 |
| DEL-PW-02 | 预览刷新 | 选 mysong → 选「彻底删除」→ 刷新预览 | 预览 Markdown 含 `mysong` 相关路径 |
| DEL-PW-03 | 未确认拦截 | 不勾选确认 → 点删除 | 报错提示；mysong 仍在列表 |
| DEL-PW-04 | 未选项目拦截 | 清空选择 → 点删除 | 提示「请先选择项目」 |
| DEL-PW-05 | scope 切换 | metadata ↔ artifacts ↔ all | 预览路径数量随 scope 增减 |
| DEL-PW-06 | 删除按钮样式 | 检查按钮 variant | `删除当前项目` 为 stop/危险样式 |

### Tier 3 — E2E 删除

| ID | 名称 | 步骤摘要 | 通过标准 |
|----|------|----------|----------|
| DEL-PW-07 | metadata 删除 | 创建 `pwdel_meta_*` 临时项目 → scope=metadata → 删除 | `.projects` 消失；`input/pwdel_meta_*.flac` 仍在 |
| DEL-PW-08 | artifacts 删除 | 创建 `pwdel_art_*` + 写入 slices 目录 → scope=artifacts | input 保留；`output/slices/pwdel_art_*` 消失 |
| DEL-PW-09 | all 彻底删除 | 创建 `pwdel_all_*` + 完整 fixture → scope=all | input、separated、产物、metadata 全部消失 |
| DEL-PW-10 | 删除后 UI 清空 | 删除当前选中项目 | Dropdown 切换至其他项目或空；阶段状态重置 |

### Tier 4 — 负向与边界

| ID | 名称 | 步骤摘要 | 通过标准 |
|----|------|----------|----------|
| DEL-PW-11 | 重复删除 | 对已删项目再次执行删除 | 可读提示；不崩溃 |
| DEL-PW-12 | 刷新后不再出现 | metadata 删除后点「刷新列表」 | 项目不出现（产物仍在时 scan 可能重建 — 记录行为） |
| DEL-PW-13 | 批量队列同步 | 删除项目后打开「批量队列」Tab | CheckboxGroup 不含已删项目 ID |

## 4. 临时项目约定（DEL-PW-07 ~ 10）

1. Playwright 展开「新建项目」手风琴
2. 填写唯一 `项目 ID`（前缀 `pwdel_` + 用途 + 时间戳）
3. 上传 `input/test.flac`、可选 `input/test.lrc`
4. 点击「创建项目」
5. E2E 用例按需写入 fixture：
   - `output/slices/{id}/lrc/manifest.json` + 空 flac
   - `output/separated/{id}_(Vocals)_test.flac`（touch 文件即可）
6. 展开「删除项目」，选择 scope，勾选确认，执行删除
7. `finally` 中 best-effort 清理残留（`collect_project_artifacts` + `scope=all`）
